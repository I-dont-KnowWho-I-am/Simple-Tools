Kunci Belum Dibuat

Fernet menggunakan kunci simetris 256-bit (32 byte) yang terdiri dari 16 byte kunci penandatanganan (HMAC-SHA256) dan 16 byte kunci enkripsi (AES-128-CBC).

Struktur Internal Kunci (32 Bytes):

Signing Key (16 bytes - HMAC-SHA256): - Digunakan untuk menghasilkan & memverifikasi integritas signature
Encryption Key (16 bytes - AES-128-CBC): - Digunakan untuk mengenkripsi & mendekripsi payload data

Fernet membungkus data dengan spesifikasi biner ketat: Version (0x80) | Timestamp (8B) | IV (16B) | Ciphertext | HMAC (32B). Masukkan token untuk melihat anatomi struktur byte-nya:

Version (1 byte) - Wajib 0x80 (128 desimal)
Waktu Pembuatan (Timestamp) - -
IV (16 bytes) - Inisialisasi unik AES-CBC acak
Ciphertext (AES-128-CBC) - Data terenkripsi (PKCS#7 padded)
HMAC Signature (32 bytes) - Pemeriksaan integritas SHA-256

Bagaimana Kriptografi Fernet Bekerja?

1. Keamanan Simetris Otentikasi

Fernet menjamin tidak hanya kerahasiaan data (confidentiality), tetapi juga integritas dan otentisitas data (data integrity & authenticity). Artinya, pesan tidak dapat dibaca orang lain, dan jika ada pihak yang memodifikasi walau 1 bit pun, dekripsi akan gagal seketika.

2. Algoritma Utama Fernet

  • AES-128 (Mode CBC): Mengamankan pesan teks dengan padding PKCS#7.
  • HMAC-SHA256: Memverifikasi bahwa token tidak dimanipulasi pihak ketiga (anti-tampering).
  • Timestamp 64-bit: Mencegah serangan replay dan memungkinkan validasi waktu kadaluarsa (TTL).
  • IV (Initialization Vector) 128-bit: Membuat hasil enkripsi selalu unik walaupun teks aslinya sama.

3. Pemrosesan 100% Sisi Klien

Semua pembuatan kunci, enkripsi, dan dekripsi berjalan murni di peramban web lokal Anda menggunakan Web Cryptography API (CSPRNG). Tidak ada lalu lintas data pesan atau kunci yang dikirim ke server manapun.
